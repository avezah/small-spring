### Key Features Documented

- **IoC Container**: Bean factory, application context, dependency injection
- **Bean Configuration**: XML and annotation-based configuration, property placeholders
- **Lifecycle Management**: Initialization, destruction, bean post processors
- **AOP**: Aspect-oriented programming with AspectJ expressions
- **Event System**: Application events and listeners
- **Resource Management**: Resource loading and abstraction
- **Component Scanning**: Automatic component discovery
- **Factory Beans**: Complex bean creation patterns
